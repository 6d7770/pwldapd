pwldapd package repository

Signed APT and dnf repositories for pwldapd, a read-only LDAP server backed by local POSIX accounts. Packages are published for amd64 and arm64 by the release workflow.

Debian 13+ and Ubuntu 25.04+ (APT)

sudo install -d /usr/share/keyrings
curl -fsSL https://6d7770.github.io/pwldapd/pwldapd-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/pwldapd-archive-keyring.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/pwldapd-archive-keyring.gpg] \
  https://6d7770.github.io/pwldapd/deb stable main" \
  | sudo tee /etc/apt/sources.list.d/pwldapd.list
sudo apt update
sudo apt install pwldapd

RHEL, Rocky, AlmaLinux 10+ and Fedora (dnf)

sudo dnf config-manager --add-repo \
  https://6d7770.github.io/pwldapd/rpm/pwldapd.repo
sudo dnf install pwldapd

On dnf 5 (Fedora 41 and later) use sudo dnf config-manager addrepo --from-repofile=https://6d7770.github.io/pwldapd/rpm/pwldapd.repo instead.

Signing key

Binary keyring: pwldapd-archive-keyring.gpg. ASCII-armored: pwldapd-archive-keyring.asc. The fingerprint is listed on the project README.
